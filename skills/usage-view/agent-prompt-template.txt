## Cache Pricing Guide (use this knowledge when interpreting cache data)
- Cache Read: 90% cheaper than regular input (e.g. $0.50/MTok vs $5/MTok for Opus)
- Cache Write 1h tier: 100% surcharge over input (e.g. $10/MTok vs $5/MTok). 1h tier = main sessions + pipe mode (claude -p)
- Cache Write 5m tier: 25% surcharge over input (e.g. $6.25/MTok vs $5/MTok). 5m tier = subtask/subagent sessions
- High cache read = conversations are being cached and reused at discount = GOOD for cost
- BUT high cache read also means context is growing large = needs management
- The key insight: caching saves money, but context growing too large wastes it. Balance is everything.

## Natural Token Pattern for Complex Work (MUST understand before writing)
