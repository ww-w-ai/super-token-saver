# /usage-view

Interactive HTML dashboard showing token usage, costs, and work patterns across your Claude Code and Codex sessions.

## Usage

```
/usage-view                  # all projects, last ~1 month
/usage-view current          # current 5-hour window only
/usage-view last 7 days      # last 7 days
/usage-view locale ja        # force Japanese
/usage-view current locale fr # combine options
```

23 languages supported: en ko ja zh es fr de pt it ru ar hi bn id ms th vi tr pl nl he sv no

Language is auto-detected from your system locale. Force it with `locale XX`.

## How It Works

1. **Analyze** — `analyze-usage.js` streams each session's JSONL transcript (Claude Code saves every conversation turn as a `.jsonl` file under `projects/` in each config folder: `~/.claude`, `$CLAUDE_CONFIG_DIR`, and any listed in `SUPER_TOKEN_SAVER_CONFIG_DIRS`; Codex rollouts under `$CODEX_HOME/sessions`), extracts token counts per model, assigns 5-hour windows, and caches results as JSON + timeline CSV. A request copied into a resumed or forked session is counted once.
2. **AI Insights** — An LLM subagent reads the aggregated data and writes cost analysis, work pattern observations, and actionable tips
3. **Build** — `build-report.js` injects report data, AI analysis, and locale translations into the HTML template
4. **Open** — The self-contained HTML file opens in your default browser

The entire pipeline runs in a background agent. You can keep working while it generates.

## Dashboard Sections

### Cost Calendar

Monthly calendar heatmap colored by daily cost. Click any day to see its 5-hour windows. Rate-limited windows are marked.

### Token Breakdown

Summary table showing input, output, cache write (5m/1h), and cache read tokens with per-model pricing. Donut chart visualizes the cost distribution.

### Hourly Cost Pattern

Bar chart showing cost by hour-of-day across all sessions. Identifies your peak work hours.

### Session Detail

Each 5-hour window expands to show individual sessions. Sessions are grouped by type:

| Type | Description |
|------|-------------|
| **Main** | Top-level interactive sessions started by the user |
| **Subtask** | Background agents spawned by a main session (linked to parent) |
| **Programmatic** | Sessions started via `claude -p` or automated pipelines |
| **Batch** | Multiple sessions with identical first messages (e.g., repeated skill runs) |
| **/s-continue restore** | Sessions that used `/s-continue` to restore previous context |

Each session card shows:

- **First / last message** — What you asked and where the conversation ended
- **Token counts** — Input, output, cache write, cache read with formatted numbers (K/M/B)
- **Cost** — Total cost for that session based on per-model pricing
- **Duration** — Session active time
- **Model** — Which Claude model was used
- **Subtask count** — How many background agents were spawned (if any)

Clicking a session card expands it to show the full token breakdown table with per-category subtotals.

In `current` mode, the most recent 5-hour window's session detail is pre-opened so you can immediately see what you spent in this window.

### AI Analysis

Up to 4 sections generated by an LLM subagent:

1. **Cost Analysis** — Total spend, daily average, cache efficiency, per-session cost
2. **Work Patterns** — Peak hours, session length trends, main vs subtask distribution
3. **Plugin Impact** — Before/after comparison if plugin install date is detected
4. **Tips** — Actionable suggestions for reducing token usage

### Account Tabs

Rate limits and 5-hour windows belong to a login account. With two or more accounts on record, the dashboard shows one tab per account, the current login first; each tab is a full report of that account's rows. Claude Code records the account at session start and after `/login`; Codex CLI 0.157+ records it once per rollout. Accounts are stored as a 12-digit one-way hash. Codex tabs show a token total instead of a cost.

### Alert Timeline

Displays cost warnings and context size alerts that fired during sessions, sorted chronologically.

## Output

- **File**: `/tmp/cc-usage-report-{timestamp}.html` (self-contained, shareable)
- **Cache**: `~/.claude/super-token-saver-data/{projectName}/{sessionId}/summary.json` and `timeline.csv`
- **Pricing**: `scripts/model-pricing.json` — per-model token costs from Anthropic's published pricing

Use `--force` flag via the runner script to bypass cache and re-analyze all sessions.
